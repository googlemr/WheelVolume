# 反馈渠道

欢迎反馈 bug、提出功能建议或参与讨论。请选择合适渠道：

## Bug 报告

使用 [Bug 报告模板](https://github.com/googlemr/WheelVolume/issues/new?template=bug_report.yml) 提交 Issue。

提交前请附上：

- macOS 版本（如 14.5）
- 芯片型号（如 M2 Pro）
- WheelVolume 版本（`WheelVolume --version`）
- 复现步骤与预期/实际表现
- 日志：`/tmp/wheelvolume/err.log`

## 功能建议

使用 [功能建议模板](https://github.com/googlemr/WheelVolume/issues/new?template=feature_request.yml)。请说明使用场景与期望行为，而不只是方案。

## 提问与讨论

- [GitHub Discussions](https://github.com/googlemr/WheelVolume/discussions) — 使用问题、经验分享、开放讨论
- [常见问题](FAQ.md) — 先查这里，很多问题已有答案

## 安全问题（请不要公开提交）

若发现安全相关漏洞（如权限滥用、代码执行风险），**不要**创建公开 Issue。请通过 GitHub 的
[私密安全报告](https://github.com/googlemr/WheelVolume/security/advisories/new) 提交，
或直接在仓库页面点 `Security` → `Report a vulnerability`。

维护者会在收到后尽快 privately 回复。

## 代码贡献

参见 [贡献指南](../CONTRIBUTING.md)。PR 请关联对应 Issue。

## 行为准则

参与本项目即表示同意遵守 [行为准则](../CODE_OF_CONDUCT.md)。
