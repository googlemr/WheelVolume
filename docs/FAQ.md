# 常见问题

## 滚轮完全没反应

1. 先确认鼠标在**屏幕最顶部边缘**（默认 8pt，约一根手指厚度以内）。
   离开该区域时本软件故意不处理任何滚轮事件。
2. 设置页看权限状态；缺少辅助功能权限就去系统设置勾选 WheelVolume。
3. 从 1.x / 2.0.x 升级后，旧的授权条目可能仍绑定旧签名：取消勾选再重新勾选。

## 按住 Ctrl 时音量也变了

v2.1.0 起不存在此路径：事件回调只计算一个 `mode`，Ctrl 按下时直接进入亮度分支，
不写音量。若仍观察到音量变化，请确认运行的版本是 v2.1.0：

```bash
/Applications/WheelVolume.app/Contents/MacOS/WheelVolume --version
```

## 亮度没变化

本软件通过 VESA DDC/CI 控制外接显示器亮度（与 F1/F2 同一通路），
已在 Mac mini M4 + HDMI 外接显示器上实测读写成功。
若显示器不支持 DDC/CI，则无法调节；可用 `m1ddc get luminance` 一类工具确认。
设置页"运行状态"会显示当前显示器是否支持。

## 调节时没有系统浮层

软件调用系统 OSD（`com.apple.OSDUIHelper`）显示原生音量/亮度反馈。
从 macOS 26 起，系统不再为程序化修改弹出该浮层，因此可能看不到提示。
软件不绘制替代界面。可在设置里开启"在菜单栏显示音量百分比"读取当前值。

## 为什么会停在 0% 或 100%

规格要求在边界处停止。连续下滑到 0% 后再下滑无效；上滑到 100% 后再上滑无效。

## 热区太小/太大

设置 → 顶部边缘热区 → 调滑块（2–48pt）或选预设。默认 8pt。
此前版本没有热区配置项，这是 v2.1.0 新增的。

## 打开时提示"应用程序没有响应"

那是 1.x 的缺陷（命令行程序塞进 .app，未初始化 `NSApplication`），
v2.0.0 起已修复。若仍出现，说明装的是旧版，请升级。

未公证应用的正常 Gatekeeper 流程或旧包签名问题。详见 [安装说明](INSTALL.md)。
