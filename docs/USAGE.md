# 使用说明

## 基本操作

| 操作 | 效果 |
| --- | --- |
| 按住 `Option`（⌥）+ 滚轮上滑 | 音量减小 |
| 按住 `Option`（⌥）+ 滚轮下滑 | 音量增大 |
| 按住 `Fn` / 地球键 + 滚轮 | 同上（可在设置中关闭） |
| 不按修饰键滚动 | 正常滚动页面，完全不受影响 |

调节时屏幕下方会出现音量浮层（HUD），0.85 秒后自动淡出。

## 菜单栏

菜单栏常驻一个扬声器图标，点击可以看到：

- 当前音量（静音时标注"静音"）
- **设置…** — 打开设置窗口
- **打开辅助功能设置…** — 跳转到系统设置对应的权限页
- **登录时自动启动** — 勾选即写入 LaunchAgent，取消即移除
- **关于 WheelVolume** — 版本信息
- **退出 WheelVolume**

设置里勾选"在菜单栏显示音量百分比"后，图标右侧会直接显示 `42%` 这类数字。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| Option 触发 | 开 | 按住 ⌥ 时接管滚轮 |
| Fn / 地球键触发 | 开 | 按住 Fn 时接管滚轮 |
| 每格调节 | 2.0% | 范围 0.2%–10%，可用滑块或预设按钮 |
| 调节间隔 | 25 毫秒 | 越小越跟手；"极顺滑"不限制（适合触控板） |
| 反转方向 | 关 | 开启后变为下滑减小、上滑增大 |
| 显示音量浮层 | 开 | 关闭后只在菜单栏反馈 |
| 菜单栏显示百分比 | 关 | 图标旁显示数字 |
| 登录时自动启动 | 关 | 通过 `~/Library/LaunchAgents` 实现 |

所有改动即时生效并写入 `UserDefaults`（bundle id `com.shanlin.WheelVolume`），
不需要重启应用。

## 精细度怎么选

- **1%**：日常最舒服，一次滑动能覆盖 0–100%，但不会一滑到底。
- **0.2%–0.5%**：修音、听细节时用，需要滑很多次。
- **5%–10%**：触控板或高阻尼滚轮，想用小幅度动作快速调整。

搭配"调节间隔"一起调：间隔越大，单次滚动能触发的调节次数越少，
在灵敏的触控板上更不容易过冲。

## 触控板说明

滚轮事件在触控板上表现为双指滑动的"滚动"，逻辑一致。若方向感觉相反，
勾选"反转方向"，或先在 系统设置 → 触控板 中确认"自然滚动"设置。

## 命令行参数

```bash
WheelVolume --version          # 输出：WheelVolume 2.0.0 (arm64-apple-macos13.0)
WheelVolume --help             # 用法提示
```

## 配置文件位置

| 内容 | 路径 |
| --- | --- |
| 偏好设置 | `~/Library/Preferences/com.shanlin.WheelVolume.plist` |
| 开机启动 | `~/Library/LaunchAgents/com.shanlin.WheelVolume.plist` |
| 应用本体 | `/Applications/WheelVolume.app` |

重置为默认：设置窗口底部 **恢复默认**，或

```bash
defaults delete com.shanlin.WheelVolume
```
